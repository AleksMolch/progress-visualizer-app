# ProgressPrivate

Privacy-first мобильное приложение для отслеживания прогресса через фотографии.

Главный принцип: фотографии и метаданные прогресса хранятся локально на устройстве.
Без рекламы, без аналитики, без облачного AI.

## MVP features

- Локальные проекты прогресс-фото
- Съёмка через камеру
- Ghost overlay для точного повторения ракурса
- Сетка-направляющая поверх камеры
- Локальное хранение фото в sandbox приложения
- Локальное хранение метаданных (зашифровано)
- Сравнение фотографий до/после
- Биометрическая защита
- Локальные напоминания (без сервера)
- Экран «Поддержать разработчика» (premium — временная dev-заглушка)
- Псевдо-timelapse (показ прогресса в динамике, без видеофайла)
- Экспорт фото в галерею только по явному действию пользователя

## Не входит в MVP

- Реклама
- Analytics SDK
- Cloud AI / ML
- Облачный бэкап
- Автоматическая синхронизация
- Генерация видео-timelapse (нативный модуль, отложено — см. DECISIONS.md)
- In-App Purchase / Premium-оплата (отложен, см. DECISIONS.md)

## Development notes

Проект использует native-модули (MMKV и др.),
поэтому целевая среда разработки — development build, а не Expo Go.

```bash
npx expo run:ios
npx expo run:android
```
