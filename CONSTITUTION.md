# CONSTITUTION — НЕИЗМЕНЯЕМЫЕ ПРАВИЛА ПРОЕКТА

> Этот файл обязателен к чтению в начале каждой сессии и каждой фазы.
> Если решение противоречит этому файлу — решение неверно.

## Продукт

ProgressPrivate — приватное мобильное приложение для отслеживания прогресса
через фотографии.

Основная ценность:

- фото хранятся локально
- пользовательские данные хранятся локально
- нет рекламы
- нет аналитики
- нет облачного AI
- нет передачи фотографий на сервер

Проект делается как сильный портфолио-проект с production-like архитектурой,
но без бессмысленного оверинжиниринга.

## Жёсткие запреты

1. Запрещено отправлять фотографии пользователя на сервер.
2. Запрещено отправлять метаданные фотографий на сервер.
3. Запрещены рекламные SDK.
4. Запрещены analytics/tracking SDK.
5. Запрещён cloud AI/ML.
6. На первом этапе запрещён ML вообще.
7. Запрещён cloud backup по умолчанию.
8. Запрещено сохранять фото в общую галерею без явного действия пользователя.
9. Запрещено добавлять network/API слой без отдельного решения пользователя.

## Разрешённые исключения

В будущем могут быть разрешены:

- IAP через Apple/Google для premium/support
- открытие внешней ссылки на страницу поддержки
- экспорт фото в галерею по явному действию пользователя

Но даже в этих случаях фотографии и локальные метаданные прогресса не должны
отправляться на сервер приложения или третьих сторон.

## Приватность технически

- Фото по умолчанию хранятся в sandbox приложения
- Метаданные хранятся локально
- Основное локальное хранилище метаданных — MMKV с encryption key
- Encryption key хранится через SecureStore или аналогичный безопасный механизм
- Доступ к приложению может быть защищён биометрией
- Разрешения приложения должны быть минимальными

## Принципы кода

- TypeScript strict
- YAGNI
- Простое решение лучше сложного
- Нет `any` без комментария-обоснования
- Нет абстракций "на будущее"
- Логика хранения не должна жить в UI-компонентах
- Слой UI не должен напрямую работать с файловой системой
- Любое нетривиальное решение фиксируется в DECISIONS.md
