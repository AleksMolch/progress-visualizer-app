# TESTING — протокол проверок

## Цель

Не добиться 100% покрытия, а защитить ключевую логику:

- модели данных
- Zustand store
- storage wrappers
- чистые utils
- privacy-critical flows

## Базовые проверки

В каждой фазе, где применимо, запускать:

```bash
npm run typecheck
npm run lint
npm test
npx expo-doctor
```

Если какой-то script ещё не настроен — агент должен настроить его
в соответствующей фазе или честно написать, почему он пока недоступен.

## Unit-тесты покрывают

- создание/удаление проекта
- добавление/удаление photo metadata
- settings
- чистые функции в /src/utils
- storage wrappers там, где возможно замоканным file API

## Не автоматизировать через unit-тесты

Не нужно пытаться полностью автоматизировать:

- camera preview
- реальные permission dialogs
- биометрию
- gestures
- native notifications

Для этих частей использовать manual verification checklist из TODO.md.

## Правило TDD

Для store и utils:

1. Сначала написать тест.
2. Убедиться, что тест падает по ожидаемой причине.
3. Реализовать код.
4. Убедиться, что тест проходит.

## Запрет ложных проверок

AI-агент не имеет права писать:

- "тесты проходят"
- "проверено"
- "работает на iOS и Android"

если он реально не запускал соответствующие команды
или пользователь не подтвердил ручную проверку.

Если проверка невозможна, писать честно:

```text
Проверка не выполнена. Причина: ...
```

## Manual verification

Для UI и native-фич:

- запуск на iOS simulator, если окружение доступно
- запуск на Android emulator, если окружение доступно
- проверка permission flow
- проверка перезапуска приложения
- проверка отсутствия автосохранения в галерею
- **Predictive back (Android 13+)**: свайп назад работает на всех экранах (проект → список,
  viewer → проект, compare → проект, timelapse → проект) без конфликтов с жестами камеры
  (горизонтальный selector) и слайдером сравнения; action sheet и редактор заметки
  закрываются корректно (сначала клавиатура, потом окно).
- **Импорт фото**: выбранный из системного picker файл копируется в sandbox
  (`<app-data>/files/photos/<project-id>/`), а не остаётся ссылкой на внешнюю галерею;
  после удаления оригинала из галереи фото в приложении остаётся.
- **Экспорт фото**: подтверждающий диалог → разрешение → фото появляется в системной галерее.
- **Разрешение камеры (release/preview APK, физический Android)**: чистая установка →
  в App info присутствует разрешение «Камера»; первый вход на вкладку Camera показывает
  объяснение и кнопку «Разрешить камеру»; системный диалог появляется только по нажатию;
  «Разрешить» → превью; «Запретить» → можно запросить снова; постоянный отказ → кнопка
  «Открыть настройки приложения»; после разрешения в Settings возврат в приложение
  обновляет статус автоматически (превью без перезапуска). Проверить светлую/тёмную тему.
- **Звук затвора (release/preview APK, физический Android)**: штатный звук Expo отсутствует
  при максимальной/средней/нулевой громкости, в обычном/вибро/беззвучном режиме; фото
  сохраняется; визуальная анимация затвора работает; haptic — только при включённой настройке.
  Если звук остаётся на конкретной прошивке — зафиксировать модель/версию/регион как
  OEM-ограничение (обход через системную громкость запрещён).
- **Анимации UI**: каскад карточек проектов при входе и при возврате на вкладку; intro
  слайдера «до/после» (0%→100%→50%, прерывается жестом); пружинная доводка с инерцией;
  count-up чисел (статистика проекта, ghost %, дни в compare). При включённом
  reduce motion анимации не проигрываются (конечное состояние сразу).
- **iPad**: запуск на iPad-симуляторе (портрет) — список проектов, экран проекта, камера,
  compare, настройки, модалки не перекрываются; safe area корректна.
- **Онбординг**: на свежей установке показываются 4 шага; «Пропустить» доступен на каждом;
  «Начать»/«Пропустить» больше не показывают онбординг после перезапуска; на обновлении
  со старой версии онбординг показывается один раз; тексты на выбранном языке.
- **Политика конфиденциальности**: кнопка в Настройках открывает внешний браузер со
  страницей GitHub Pages (`privacy-policy.html`), содержимое читается на мобильном.
- **Миниатюры**: после сохранения/импорта фото рядом появляется `<имя>_thumb.jpg`;
  timeline/списки/лист выбора грузятся заметно быстрее на большом проекте; старые фото
  получают миниатюры после запуска (фоновая миграция); удаление фото удаляет оригинал и
  миниатюру; при отсутствии миниатюры показывается оригинал без ошибок.
- **Мягкий splash**: холодный запуск на iOS и Android — нет белой вспышки/скачка
  между нативным splash и JS-оверлеем; знак по центру, фон `#0B0D12`, размер 160 dp,
  это ОРИГИНАЛЬНЫЙ знак с синим лепестком (не белая версия), первый кадр
  `opacity 1`, `scale 1`; пока storage не готов — спокойное дыхание,
  после готовности — один цикл 1→1.025→1 и fade (~640 мс). Reduced Motion — без
  движения, overlay исчезает сразу. Биометрия/онбординг появляются после заставки,
  не поверх неё; повторный запуск после сворачивания не проигрывает заставку заново.
- **Иконки и разрешения (физический Android)**: иконка читается в круглой/квадратной
  маске, adaptive foreground не обрезается, monochrome различим (Android 13+); в
  `adb shell dumpsys package ru.nov.molcha.progressvisualizer` нет
  `WRITE_EXTERNAL_STORAGE` и `USE_FINGERPRINT`, есть `CAMERA` и `USE_BIOMETRIC`;
  камера/экспорт/биометрия/импорт работают.
- **EAS-профили**: `eas config --profile preview|production|production-apk` валиден;
  `preview` ставится на устройство, `production` даёт AAB, `production-apk` — APK.
- **CI**: после пуша в `main` workflow `CI` проходит (typecheck/lint/test); ошибка типа
  в PR роняет шаг Typecheck.
- **Ad placeholder (Android, вручную)**: текст не выходит за рамку и не рисуется ниже
  карточки — во всех 5 локалях, темах modern/simple/neumorphism, светлой/тёмной схеме,
  при максимальном системном размере шрифта и ширине ~360 dp; карточка растёт по
  содержимому; описание ограничено двумя строками с многоточием.
- **Каскад ad-placeholder**: на вкладке «Проекты» слот появляется вместе с карточками
  (после первой, задержка 60 мс) и перезапускается при возврате на вкладку; при одном
  проекте — тоже; empty state, Project и Settings — статичны; при Reduced Motion появление
  мгновенное; при скролле длинного списка повторной анимации нет.

## Privacy verification (финальная фаза)

Перед закрытием проекта проверить:

- нет advertising SDK
- нет analytics SDK
- нет cloud AI SDK
- нет API/network слоя
- фото не отправляются наружу
- экспорт в галерею только по явному действию пользователя
