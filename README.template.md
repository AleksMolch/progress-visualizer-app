# ProgressPrivate — приватное приложение для прогресс‑фотографий

**Отслеживайте изменения во времени: тело, растения, ремонт, что угодно.
Все фотографии остаются только на вашем телефоне.**

---

## Что это

ProgressPrivate — приложение для регулярных фотографий «до и после».
Оно помогает делать снимки с одного ракурса благодаря наложению
предыдущего фото (ghost overlay) и хранит всё локально на устройстве.

Никакой рекламы. Никакой аналитики. Никакой отправки фото в интернет.

---

## Ключевые возможности

- 📸 Съёмка прогресс‑фото с направляющим наложением предыдущего кадра
- 🔲 Сетка для точного выравнивания
- 🔒 Хранение только на устройстве, без облака
- 👆 Биометрическая защита входа
- 🖼️ Сравнение «до/после»
- 🔔 Локальные напоминания
- 📤 Экспорт в галерею — только по вашему действию

---

## Приватность

Это главная идея приложения:

- фотографии не покидают ваш телефон;
- нет рекламных и аналитических трекеров;
- приложение работает без интернета;
- вы сами решаете, экспортировать ли фото в галерею.

Подробнее — в разделе «Политика конфиденциальности» ниже.

---

## Как пользоваться

1. Создайте проект (например, «Тренировки» или «Фикус»).
2. Сделайте первое фото.
3. В следующий раз предыдущее фото появится полупрозрачным поверх камеры —
   повторите ракурс.
4. Сравнивайте снимки во времени.

## Политика конфиденциальности

- Приложение не собирает персональные данные.
- Фотографии и записи хранятся локально на устройстве.
- Данные не передаются разработчику или третьим лицам.
- Экспорт фотографий в галерею происходит только по вашему явному действию.
